## 📚 Про курс

Цей репозиторій містить повний навчальний контент з теми **«Основи алгоритмізації та програмування»** для учнів 10–11 класів загальноосвітніх шкіл України. Матеріали розроблені з використанням можливостей генеративного штучного інтелекту (Claude, GPT-4).

## 🎯 Мета курсу

- Сформувати розуміння поняття алгоритму та його властивостей
- Навчити записувати алгоритми у різних формах (словесній, блок-схемній, мовою програмування)
- Розвинути навички алгоритмічного мислення та програмування на Python
- Підготувати учнів до розв'язання задач різного рівня складності
