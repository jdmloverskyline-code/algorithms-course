# Додаткові ресурси

## 🎓 Онлайн-курси та навчання

- [Python для початківців — Pythontutor.com](http://pythontutor.com) — візуалізація виконання коду
- [Codecademy — Learn Python](https://www.codecademy.com/learn/learn-python-3) — інтерактивний курс
- [W3Schools Python Tutorial](https://www.w3schools.com/python/) — довідник з прикладами

## 📹 Відео

- YouTube канал «CS Dojo» — алгоритми та структури даних
- YouTube канал «Coding Train» — творче програмування
- «Алгоритми та структури даних» — курс від CS50 (Harvard, безкоштовно)

## 📚 Книги

- Лутц М. «Вивчаємо Python» — класичний підручник
- Бхаргава А. «Грокаємо алгоритми» — візуальний підхід до алгоритмів
- Корmen Т. та ін. «Вступ до алгоритмів» — академічний підручник

## 🛠️ Онлайн-середовища для програмування

- [repl.it](https://replit.com) — онлайн IDE з Python
- [Google Colab](https://colab.research.google.com) — Jupyter Notebooks у хмарі
- [OnlineGDB](https://www.onlinegdb.com) — онлайн компілятор

## 🎮 Навчальні ігри та тренажери

- [CheckiO](https://checkio.org) — завдання з Python у ігровому форматі
- [Codewars](https://www.codewars.com) — «ката» з програмування
- [LeetCode](https://leetcode.com) — алгоритмічні задачі

## 🏆 Олімпіадні ресурси

- [Codeforces](https://codeforces.com) — змагання з програмування
- [e-olymp.com](https://www.e-olymp.com) — українська олімпіадна платформа

## 📖 Корисні статті

- [Visualgo.net](https://visualgo.net) — візуалізація алгоритмів сортування та пошуку
- [Big-O Cheat Sheet](https://www.bigocheatsheet.com) — шпаргалка зі складності алгоритмів
