# Теоретичний блок: Основи алгоритмізації та програмування

## 1. Поняття алгоритму

**Алгоритм** — це скінченна послідовність чітких, однозначних інструкцій, виконання яких дозволяє розв'язати певну задачу або досягти певної мети за скінченний час.

Термін «алгоритм» походить від імені середньовічного математика **аль-Хорезмі** (IX ст.), який описав правила арифметичних дій.

---

## 2. Властивості алгоритму

| Властивість | Опис | Приклад порушення |
|-------------|------|-------------------|
| **Дискретність** | Алгоритм складається з окремих кроків | Нечіткий опис дії |
| **Визначеність** | Кожен крок однозначний, без двозначностей | «Додай трохи солі» |
| **Скінченність** | Алгоритм завершується за кінцеву кількість кроків | Нескінченний цикл |
| **Результативність** | Після виконання отримується результат | Відсутність виводу |
| **Масовість** | Придатний для цілого класу задач | Розв'язання лише однієї задачі |

---

## 3. Форми запису алгоритмів

### 3.1. Словесна форма

Простий опис кроків природною мовою.

**Приклад** — Алгоритм знаходження найбільшого з двох чисел:
1. Ввести числа A і B
2. Якщо A > B, то найбільше = A
3. Інакше найбільше = B
4. Вивести найбільше

### 3.2. Блок-схема

Графічне зображення алгоритму за допомогою стандартних геометричних фігур:

| Фігура | Назва | Призначення |
|--------|-------|-------------|
| Прямокутник | Процес | Обчислення, присвоєння |
| Ромб | Рішення | Умовний перехід (так/ні) |
| Паралелограм | Введення/Виведення | Ввід даних, вивід результату |
| Овал | Початок/Кінець | Термінатор алгоритму |

### 3.3. Псевдокод

Проміжна форма між словесним записом і мовою програмування.

```
ПОЧАТОК
  ВВЕСТИ A, B
  ЯКЩО A > B ТО
    max ← A
  ІНАКШЕ
    max ← B
  КІНЕЦЬ_ЯКЩО
  ВИВЕСТИ max
КІНЕЦЬ
```

### 3.4. Мова програмування (Python)

```python
# Знаходження найбільшого з двох чисел
a = int(input("Введіть перше число: "))
b = int(input("Введіть друге число: "))

if a > b:
    max_num = a
else:
    max_num = b

print(f"Найбільше число: {max_num}")
```

## 4. Основні алгоритмічні конструкції

### 4.1. Лінійна (послідовна) конструкція

Команди виконуються одна за одною у строгому порядку.

```python
# Приклад: обчислення площі прямокутника
довжина = float(input("Довжина: "))
ширина = float(input("Ширина: "))
площа = довжина * ширина
print(f"Площа = {площа}")
```

### 4.2. Розгалуження (умовна конструкція)

Залежно від умови виконується одна з гілок алгоритму.

**Повне розгалуження:**
```python
# Визначення парності числа
n = int(input("Введіть число: "))
if n % 2 == 0:
    print(f"{n} — парне")
else:
    print(f"{n} — непарне")
```

**Неповне розгалуження:**
```python
# Перевірка на позитивність
x = float(input("Введіть число: "))
if x > 0:
    print("Число позитивне")
```

**Вкладене розгалуження (elif):**
```python
# Оцінка за балами
бал = int(input("Введіть бал (0-100): "))
if бал >= 90:
    print("Відмінно")
elif бал >= 75:
    print("Добре")
elif бал >= 60:
    print("Задовільно")
else:
    print("Незадовільно")
```

### 4.3. Циклічна конструкція

Повторення певної групи команд.

**Цикл з лічильником (for):**
```python
# Таблиця множення числа 7
for i in range(1, 11):
    print(f"7 × {i} = {7 * i}")
```

**Цикл з умовою (while):**
```python
# Сума цифр числа
n = int(input("Введіть число: "))
сума = 0
while n > 0:
    сума += n % 10
    n //= 10
print(f"Сума цифр: {сума}")
```

## 5. Алгоритми обробки масивів

Масив (список) — структура даних для зберігання однотипних елементів.

```python
# Знаходження мінімального елемента масиву
числа = [34, 12, 67, 5, 89, 23]
мін = числа[0]
for x in числа:
    if x < мін:
        мін = x
print(f"Мінімальний елемент: {мін}")

# Або вбудованою функцією:
print(f"Мінімальний елемент: {min(числа)}")
```

## 6. Алгоритми сортування

### Метод бульбашки (Bubble Sort)

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr

список = [64, 34, 25, 12, 22, 11, 90]
print("До сортування:", список)
print("Після сортування:", bubble_sort(список))
```

**Принцип роботи:** порівнюємо сусідні елементи та міняємо їх місцями, якщо попередній більший за наступний. Після кожного проходу найбільший елемент «спливає» в кінець.

## 7. Функції в програмуванні

Функція — іменований блок коду, який виконує певну дію і може бути викликаний кілька разів.

```python
def привітання(ім'я):
    """Функція виводить привітання."""
    print(f"Привіт, {ім'я}! Ласкаво просимо до курсу!")

def площа_кола(радіус):
    """Обчислює площу кола."""
    import math
    return math.pi * радіус ** 2

# Виклик функцій
привітання("Аліна")
r = 5
print(f"Площа кола з радіусом {r} = {площа_кола(r):.2f}")
```

## 8. Складність алгоритмів (базово)

**Часова складність** — кількість операцій залежно від розміру вхідних даних.

| Складність | Позначення | Опис |
|-----------|-----------|------|
| Константна | O(1) | Не залежить від розміру даних |
| Лінійна | O(n) | Час зростає лінійно |
| Квадратична | O(n²) | Час зростає як квадрат (напр., bubble sort) |
| Логарифмічна | O(log n) | Ефективні алгоритми пошуку |

> 💡 **Запам'ятайте:** чим менша складність алгоритму, тим він ефективніший для великих обсягів даних.
