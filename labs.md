## 🎨 Творчий проект: Мій калькулятор

Розробіть текстовий калькулятор з меню, який виконує:
- Базові арифметичні операції (+, -, ×, ÷)
- Знаходження НСД та НСК
- Перевірку числа на простоту
- Виведення таблиці множення

**Вимоги:**
- Використовуйте функції для кожної операції
- Додайте обробку помилок (ділення на 0, нечисловий ввід)
- Програма повинна працювати до вибору опції «Вихід»

```python
def меню():
    print("=== Калькулятор ===")
    print("1. Арифметичні операції")
    print("2. НСД та НСК")
    print("3. Перевірка простого числа")
    print("4. Таблиця множення")
    print("0. Вихід")
    return input("Ваш вибір: ")

while True:
    вибір = меню()
    if вибір == '0':
        print("До побачення!")
```
