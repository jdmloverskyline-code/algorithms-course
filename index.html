Основні поняття алгоритмізації та програмування на Python

1. Поняття алгоритму

Алгоритм — це скінченна послідовність чітких, однозначних інструкцій, виконання яких дозволяє розв'язати певну задачу або досягти мети за скінченний час.

Термін «алгоритм» походить від імені середньовічного математика аль-Хорезмі (IX ст.), який описав правила арифметичних дій.

🧠

Простий приклад алгоритму: рецепт приготування страви. Він має чіткі кроки, завершується (страва готова) і дає результат.

2. Властивості алгоритму

ВластивістьОписПриклад порушення
ДискретністьСкладається з окремих кроківНечіткий опис дії
ВизначеністьКожен крок однозначний«Додай трохи солі»
СкінченністьЗавершується за кінцеву кількість кроківНескінченний цикл
РезультативністьПісля виконання отримується результатВідсутність виводу
МасовістьПридатний для класу задачРозв'язання лише однієї задачі

3. Основні алгоритмічні конструкції

▶ Лінійна конструкція
довжина = float(input("Довжина: "))
ширина = float(input("Ширина: "))
площа = довжина * ширина
print(f"Площа = {площа}")
◇ Розгалуження
n = int(input("Число: "))
if n % 2 == 0:
    print(f"{n} — парне")
else:
    print(f"{n} — непарне")
↻ Цикл
for i in range(1, 11):
    print(f"7 × {i} = {7 * i}")

4. Вкладені конструкції — elif

бал = int(input("Введіть бал (0-100): "))
if бал >= 90:
    print("Відмінно — 12 балів")
elif бал >= 75:
    print("Добре — 9-11 балів")
elif бал >= 60:
    print("Задовільно — 6-8 балів")
else:
    print("Незадовільно — 1-5 балів")

5. Цикл while

Використовується, коли кількість повторень заздалегідь невідома.

# Сума цифр числа
n = int(input("Введіть число: "))
сума = 0
while n > 0:
    сума += n % 10   # додаємо останню цифру
    n //= 10         # відкидаємо останню цифру
print(f"Сума цифр: {сума}")

6. Функції

Функція — іменований блок коду, який виконує певну дію і може бути викликаний кілька разів.

def площа_кола(радіус):
    """Обчислює площу кола."""
    import math
    return math.pi * радіус ** 2

r = float(input("Введіть радіус: "))
print(f"Площа кола = {площа_кола(r):.2f}")

7. Сортування методом бульбашки

Принцип: порівнюємо сусідні елементи та міняємо їх місцями, якщо попередній більший за наступний. Після кожного проходу найбільший елемент «спливає» в кінець.

def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n - i - 1):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr

список = [64, 34, 25, 12, 22, 11, 90]
print("До:", список)
print("Після:", bubble_sort(список))

8. Складність алгоритмів

СкладністьПозначенняОпис
КонстантнаO(1)Не залежить від розміру даних
ЛінійнаO(n)Час зростає лінійно
КвадратичнаO(n²)Bubble Sort — два вкладені цикли
ЛогарифмічнаO(log n)Двійковий пошук
⚠️

Чим менша складність алгоритму, тим він ефективніший для великих обсягів даних. Bubble Sort (O(n²)) для мільйона елементів — дуже повільно!
